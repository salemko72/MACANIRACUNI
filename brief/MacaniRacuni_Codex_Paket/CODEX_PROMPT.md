# Zadatak za Codex — MacaniRacuni

Pročitaj `SPECIFIKACIJA.md` i pogledaj `reference/IMG_0390.jpeg`.

Implementiraj **samo Fazu 1**: React + TypeScript + Vite, mobile-first PWA, moderan i minimalistički izgled inspirisan paletom reference (ne kopiraj raspored bankarske aplikacije). Naziv aplikacije svuda mora biti **MacaniRacuni**.

Kreiraj ekran Mjesec sa stalnom listom očekivanih računa po obračunskom mjesecu, zasebnim statusima "stigao" i "plaćen", ekran detalja računa, statistiku i jednostavan placeholder za skeniranje. Dodaj Sarajevo i Nišiće kao dvije nekretnine. Svi testni podaci moraju biti jasno označeni kao DEMO. Implementiraj localStorage i osnovne testove domenske logike.

Ne povezuj stvarni Gmail, kameru/OCR, AI, Cloudflare, push niti plaćanje u ovoj fazi. Ne ugrađuj stvarne račune ili privatne podatke. Nakon rada pokreni build/testove i napiši tačne upute za pokretanje.

Predloženi lokalni folder: `C:\MacaniRacuni\`. Ako u folderu već postoji kod, prvo ga pregledaj i nemoj ga prepisivati bez potrebe.
